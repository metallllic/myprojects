# myprojects
My personal projects, apps and experiments in one place.

## Projects

- **[Flash Reader](https://metallllic.github.io/myprojects/)** (`index.html`): a speed reader that shows one word at a time. It imports pasted text, TXT, PDF and EPUB files and keeps your place in a book map. It can also browse a GitHub repository and import a book straight from it. Everything stays in your browser.
